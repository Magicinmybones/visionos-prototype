# VisionOS prototype

Static landing page adapted from `visionos (3).html`. The font and background images are in `public/assets/`.

## Local preview

```bash
npm install
npm run dev
```

## Deploy to Cloudflare Pages

```bash
npm run deploy
```

The signup form currently shows a confirmation in the browser and does not send or store email addresses. Links with `href="#"` are placeholders from the supplied prototype.
